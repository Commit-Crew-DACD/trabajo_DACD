# SmartTrip Java App

Aplicación Java que consulta múltiples fuentes de datos para obtener vuelos entre LPA, MAD y BCN, integra eventos desde Ticketmaster API y genera paquetes recomendados de vuelo + evento.

## Tecnologías
- Java
- REST APIs
- JSON
- OOP
- Git/GitHub

## Funcionalidades
- Consulta vuelos disponibles
- Búsqueda de eventos por ciudad
- Combinación inteligente vuelo + evento
- Recomendaciones de paquetes
